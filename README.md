# Hi, I'm Tooba Mujtaba

**Bioinformatics analyst** | miRNA biomarkers · cancer genomics · reproducible analysis pipelines

I turn public and clinical omics data into publication-ready results. My work focuses on microRNA biomarkers in cancer, built on TCGA/GDC and GEO data, survival modelling and clean, reproducible Python pipelines.

## What I do

- **Cancer omics analysis:** TCGA/GDC API pipelines, GEO datasets, differential expression, multi-cohort integration
- **Biomarker discovery:** tissue and circulating miRNA signatures, survival analysis (Kaplan-Meier, Cox regression), diagnostic ROC modelling
- **Statistics:** study design review, sample-size planning, multiple-testing correction, clinical subgroup analysis
- **Reproducible tools:** tested Python packages and Streamlit web apps for wet-lab researchers

**Stack:** Python (pandas, SciPy, statsmodels, lifelines, scikit-learn) · R (limma, survival, clusterProfiler) · Google Colab · Streamlit · Git
